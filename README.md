# Audi Telegram Digest

Бот, который собирает автомобильные новости, переписывает их по стилю
и публикует в Telegram-канал/группу. Всё управление — через обычный
текст в Claude Code, без Cowork и без ручного запуска скриптов на своём
компьютере.

## Как это работает

1. В чате: «Найди новости» — ищу по `instructions/BRIEF.md`, проверяю
   дубли по `used-news.md`, пишу тексты по `instructions/STYLE.md`,
   сохраняю в `pipeline_state.json` со статусом `candidate`.
2. Ты проверяешь тексты, просишь правки при необходимости.
3. «Запланируй пост X на 14:30» — статус меняется на `ожидает`,
   выставляется `scheduledFor` в UTC.
4. Изменения пушатся в этот репозиторий.
5. GitHub Actions (`.github/workflows/publish.yml`) проверяет очередь
   в 07:00 / 11:30 / 16:00 UTC (10:00 / 14:30 / 19:00 МСК) и сразу после
   каждого пуша — отправляет всё, чьё время уже наступило, независимо
   от того, включён ли компьютер.

Полный список команд — в [COMMANDS.md](COMMANDS.md).

## Дашборд управления

Локальная веб-панель на Streamlit — для настройки источников, критериев
отбора, каналов публикации и работы с очередью, без правки файлов вручную.

```bash
pip install -r requirements.txt
streamlit run dashboard.py
```

Или просто запусти `run_dashboard.bat`. Откроется в браузере на
`http://localhost:8501`.

**Что умеет дашборд:**
- 📋 Очередь — смотреть/редактировать/удалять посты, менять статус, время, канал
- 🌐 Источники — добавлять/убирать сайты для поиска (`sources.json`)
- 📝 Критерии — редактировать `instructions/BRIEF.md` и `STYLE.md`
- 📡 Каналы — управлять каналами публикации (`channels.json`)
- 📜 Логи — смотреть `publish_log.txt` и `used-news.md`
- Git Pull/Push прямо из панели, кнопка ручного запуска `telegram_publisher.py`

**Чего дашборд не делает:** сам не ищет и не пишет посты — это по-прежнему
делает Claude в чате (см. workflow выше). Дашборд только показывает
результат и позволяет всё настроить.

## Структура

```
instructions/BRIEF.md   — какие новости брать и в каком приоритете
instructions/STYLE.md   — как писать пост (структура, тон, ссылка)
sources.json             — список источников для поиска (редактируется в дашборде)
channels.json            — каналы публикации в Telegram (редактируется в дашборде)
dashboard.py             — локальный веб-дашборд (Streamlit)
src/telegram_publisher.py — скрипт отправки в Telegram
pipeline_state.json     — очередь постов и их статусы
used-news.md            — история публикаций (дедупликация)
publish_log.txt         — лог отправлений
.github/workflows/publish.yml — облачный запуск по слотам 10:00/14:30/19:00 МСК
```

## Токен бота

Локально — файл `telegram_token.txt` (в `.gitignore`, никогда не коммитится).
В облаке — GitHub Secret `TELEGRAM_BOT_TOKEN`, скрипт сам выбирает источник.
